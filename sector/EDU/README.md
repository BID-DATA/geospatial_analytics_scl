# Education (EDU)

This folder contains the **Education (EDU)** component of the *Geospatial Analytics SCL* repository. It provides documentation, metadata, and quality reports for the **Education Facilities** dataset in Latin America and the Caribbean (LAC), and includes scripts/exercises to facilitate analysis and exploration.

## Introduction

This folder provides documentation, metadata, and data quality reports for the public Education Facilities dataset in Latin America and the Caribbean (LAC), available through the [SCL Data Lake](https://scldata.iadb.org/app/collections). It also includes exercises and scripts to facilitate analysis and exploration of these geospatial datasets, helping users understand the data, assess quality, and apply it in analytical or policy-relevant contexts.

## Folder contents 

- **`dictionary.pdf`**  
  Comprehensive data dictionary for the Education Facilities dataset, including variable definitions, sources, accessibility status (public/private), and an overview of available variables. :contentReference[oaicite:4]{index=4}

- **`quality reports/`**  
  Country-level quality control reports summarizing common data issues and cross-checking aggregated numbers with other references. :contentReference[oaicite:5]{index=5}

- **`exercises/`**  
  R scripts with exercises related to the Education Facilities dataset.

- **`metadata.csv`**  
  Metadata for the Education Facilities dataset. :contentReference[oaicite:7]{index=7}

## Data access

The files in this folder are based on the Education Facilities dataset, developed by the **CIMA team** (Centro de Información para la Mejora de los Aprendizajes) using official sources obtained either from public data or information provided directly by national counterparts.

- The use, reproduction, redistribution, or full/partial publication of this data layer requires **prior authorization from the CIMA team**. 
- The dataset is available upon request via the [SCL Data Lake folder](https://scldata.iadb.org/app/folder/768E6E2A-DEFF-4BF9-B62D-E32518B15180). 
- For access or further information, please contact: **Elena Arias Ortiz (eariasortiz@iadb.org)**.
